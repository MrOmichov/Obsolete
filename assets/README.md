# Подготовленные ассеты

PNG-файлы нарезаны из исходных листов в `Obsolete_generated_assets/assets`. JPG-источники не изменялись.

## Состав

- `world/<объект>/row_01..03/panel_01..06.png` — 90 панелей с пяти листов окружения. Строки оставлены в исходном порядке, а панели названы нейтрально: назначение части вариантов на листах неоднозначно.
- `characters/player/{idle,run,interact}/frame_01..06.png` — 18 кадров игрока.
- `characters/npc/{microchip,floppy_disk,diode}/{idle,interact}/frame_01..06.png` — по 12 кадров для трёх NPC.
- `characters/npc/resistor/{idle,interact}/frame_01..06.png` — 12 кадров NPC-резистора. Отдельный посторонний рисунок ниже кадров на исходном листе пропущен.
- `characters/npc/unassigned_resistor_sheet/` — 18 кадров с листа, ошибочно помещённого в исходную папку `NPC_Capacitor`: на изображении тоже резистор. Неподписанная средняя строка сохранена как `row_02_unlabeled`.

Всего подготовлено 174 PNG. Кадры персонажей сохранены без масштабирования, снабжены прозрачностью и выровнены по центру и нижнему краю общей рамки своей анимации. 62 панели с отдельными предметами также снабжены прозрачностью; 28 цельных плиток пола сохранены без изменений.

## Примечания

Шахматная подложка запечена в исходные JPEG. Для 84 кадров персонажей используются маски силуэта BiRefNet, для 62 отдельных предметов — U2Net с уточнением тёмных корпусов. Маски исключают рамки исходных листов, сохраняют отдельные яркие искры и удаляют фоновую дымку. Цвета берутся из оригиналов; размеры PNG и положения кадров не меняются.

Повторная обработка: `scripts/remove_character_background.py --kind all` (нужны Python, Pillow, numpy, OpenCV, rembg и onnxruntime; локальные зависимости находятся в `.asset-tools/`). Модели исполняются локально, изображения не отправляются на сервер. Исходные JPG не изменяются. Резервная копия PNG до этой очистки — `.runtime/asset_cleanup_before.zip`; промежуточные маски — `.runtime/asset_alpha_masks/`. Для восстановления мировых панелей скрипт читает резервную копию, для персонажей — исходные листы и `character_source_mapping.json`.

`assets_cleanup_review.png` показывает предметы на светлой и тёмной подложках без шейдера. Часть мягких фоновых свечений исключена вместе с запечённой подложкой; основные цвета рисунка сохранены.
